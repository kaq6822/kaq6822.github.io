01.소개

소프트웨어의 본질은 현실의 어려움을 해결하는 것이라고 생각합니다. 그래서 기능을 만들기 전에 현장에서 누가 어떤 불편을 겪는지부터 파악하고, 기획 단계부터 참여해 기술적 의사결정을 주도해 왔습니다.

라톤테크에서는 금융·공공기관에 IAM/SSO 솔루션을 구축하며 대규모 계정 관리와 이기종 시스템 연동을 다뤘고, 현재는 셀바스AI에서 의료 장비 실시간 모니터링, 오디오북 음성합성(TTS) 등 프로덕트 서버를 개발하고 있습니다. 팀 안에서는 누구나 개발·배포를 자동으로 진행할 수 있는 플랫폼과 AI Agent 가이드를 만들어 운영합니다.

DDD 기반 헥사고날 아키텍처로 유지보수 비용을 낮추고 확장성을 높이는 설계, 그리고 실시간 데이터 파이프라인과 성능 최적화에 강점이 있습니다. 매년 모교와 대학에서 프로그래밍 강의도 이어가고 있습니다.

03.경력

셀바스AI

2022.07 – 현재

백엔드 엔지니어 · 프로덕트 서버 개발

  • 의료 장비 실시간 모니터링 웹 서비스

    현장기존 모니터링 SW는 스탠드얼론으로 동작해 설치된 PC 한 대에서만 볼 수 있었고, 연결 가능한 장비 수가 적으며 이력 확인과 기능 확장이 어려움.

    해결서버 기반 웹 서비스로 전환해, 의료진이 여러 PC의 브라우저에서 병동별로 더 많은 장비와 환자를 한곳에서 실시간 모니터링하고 응급 알람을 즉시 확인할 수 있도록 설계·개발. OLAP DB 기반 저장/조회 구조로 이력 조회를 뒷받침하고, 브로드캐스팅·구독 통신 아키텍처와 JMS(ActiveMQ)로 실시간 전달을 구현.

    • Java · Spring
    • OLAP
    • ActiveMQ

  • 체성분 분석 모바일 앱 서버

    현장측정 장비를 저렴하게 보급하려면 디스플레이를 없애거나 줄여야 하지만, 그러면 사용자가 결과를 제대로 확인하기 어려움.

    해결앱이 장비의 디스플레이 역할을 하도록 백엔드 개발을 주도. Spring·AWS로 기기 데이터 수집부터 변화 추이·리포트 제공까지 구축하고, 한 장비를 여러 사람이 함께 쓸 수 있도록 구성. MVP 코드베이스를 DDD 기반 헥사고날 아키텍처로 리팩토링하고 애자일 프로젝트 관리 체계도 직접 구축.

    • Spring
    • AWS
    • DDD · 헥사고날

  • 군 응급 원격진료 서비스

    현장군 특성상 의료진이 없는 오지에서도 응급 환자가 발생할 수 있음.

    해결상황실이 사고 현장과 군 병원 의료진을 화상으로 연결해, 의료진이 현장 응급 조치를 지도할 수 있는 서비스를 개발. Coturn 중계 서버로 폐쇄망–인터넷망 사이 WebRTC 연결을 열고 Docker Swarm 환경에서 운용했으며, STT API 게이트웨이를 신규 개발해 실시간 자막을 스트리밍.

    • WebRTC
    • Docker Swarm
    • STT · API GW

  • 오디오북 특화 음성합성(TTS) 플랫폼

    현장오디오북을 만들려면 성우를 고용해 사람이 일일이 녹음해야 함.

    해결성우 없이도 대용량 텍스트를 오디오북으로 생산할 수 있는 TTS 플랫폼을 제공. Go 기반 서비스의 리브랜딩·고도화 아키텍처를 설계하고, pprof로 OOM을 추적해 튜닝하고 Race condition을 해결해 안정화. ELK 모니터링과 결제·DB 공통 모듈화를 진행하고, ePub/PDF 파서, OCR(PP-Structure), DAW 편집 기능을 구현.

    • Go
    • pprof
    • ELK
    • OCR

라톤테크

2015.08 – 2022.06

IAM/SSO 솔루션 구축 · 일부 프로젝트 PL

  • 금융·공공 IAM/SSO 인증 인프라

    현장수십만 계정이 여러 이기종 시스템(EAI·API·DB)에 흩어져 있어, 사용자는 시스템마다 로그인하고 관리자는 계정을 따로 관리해야 함.

    해결국민건강보험공단, 한화생명, NH농협, 한국은행, 카카오뱅크, SK플래닛 등의 차세대 시스템 전환 프로젝트에 IAM/SSO 솔루션을 구축. 인증 아키텍처를 설계·구현하고 이기종 시스템 연동과 OTP 인증 서버 구축을 담당.

    • IAM · SSO
    • OTP
    • EAI 연동

일하는 방식

  • 누구나 쓰는 팀 개발 플랫폼 · AI Agent 가이드

    현장개발·배포 과정이 특정 지식을 가진 사람에게 의존하고, 팀원마다 AI 산출물의 품질이 달라짐.

    해결지식이 없어도 개발 요소와 배포를 자동으로 진행할 수 있는 팀 내 플랫폼을 만들어 배포·운영. AI Agent 가이드를 유지관리하며 모든 팀원의 AI 산출물이 일정한 품질을 유지하도록 꾸준히 개선. 데이터 검증·마이그레이션 툴 개발, 코드 컨벤션 문서화, 사내 기술 세미나도 같은 맥락에서 진행.

    • 개발 플랫폼
    • 배포 자동화
    • AI Agent 가이드
