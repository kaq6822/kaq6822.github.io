강범준

현장의 불편을 소프트웨어로 푸는 11년차 백엔드 엔지니어

기술보다 그 기술로 풀어야 할 현장의 문제를 먼저 봅니다. 병동 환자 실시간 모니터링, 오지 응급 환자를 위한 원격진료, 성우 없이 만드는 오디오북까지 오프라인에서 사람이 겪는 어려움을 소프트웨어로 덜어내는 일을 10년 넘게 해 왔습니다. 도구와 언어는 문제에 맞춰 고르고, 요즘은 AI Agent와 함께 더 빠르게 풀어 갑니다.

소개

소프트웨어의 본질은 현실의 어려움을 해결하는 것이라고 생각합니다. 그래서 기능을 만들기 전에 현장에서 누가 어떤 불편을 겪는지에 집중하며, 기획 단계부터 참여해 기술적 의사결정을 주도해 왔습니다.

한 번 만들고 끝나는 시스템이 아니라 현장에서 오래 쓰일 수 있도록 유지보수와 확장이 쉬운 구조를 고민하고, 실시간 데이터 처리나 성능 문제는 원인을 끝까지 추적해 풉니다. 팀 안에서는 누구나 개발·배포를 자동으로 진행할 수 있는 플랫폼과 AI Agent 하네스를 만들어 운영하고, 매년 모교와 대학에서 프로그래밍 강의도 이어가고 있습니다.

대표 작업

셀바스AI

의료 장비 실시간 모니터링 웹 서비스

현장
기존 모니터링 SW는 스탠드얼론으로 동작해 설치된 PC 한 대에서만 볼 수 있었고, 연결 가능한 장비 수가 적으며 이력 확인과 기능 확장이 어려웠습니다.
해결
서버 기반 웹 서비스로 전환했습니다. OLAP DB 기반 저장·조회 구조로 이력 조회를 뒷받침하고, 브로드캐스팅·구독 통신 아키텍처와 JMS(ActiveMQ)로 실시간 전달을 구현했습니다.
변화
PC 한 대에서만 확인→여러 PC의 브라우저에서 병동별로 더 많은 장비와 환자를 실시간 모니터링하고, 응급 알람을 즉시 확인

셀바스AI

군 응급 원격진료 서비스

현장
군 특성상 의료진이 없는 오지에서도 응급 환자가 발생할 수 있습니다.
해결
상황실이 사고 현장과 군 병원 의료진을 화상으로 연결하는 서비스를 개발했습니다. Coturn 중계 서버로 폐쇄망–인터넷망 사이 WebRTC 연결을 열어 Docker Swarm 환경에서 운용했고, STT API 게이트웨이를 신규 개발해 실시간 자막을 스트리밍했습니다.
변화
현장에 의료진이 없음→군 병원 의료진이 화상으로 현장 응급 조치를 지도

셀바스AI

오디오북 특화 음성합성(TTS) 플랫폼

현장
오디오북을 만들려면 성우를 고용해 사람이 일일이 녹음해야 합니다.
해결
Go 기반 TTS 서비스의 리브랜딩·고도화 아키텍처를 설계했습니다. pprof로 OOM을 추적해 튜닝하고 Race condition을 해결해 서비스를 안정화했으며, ELK 모니터링과 결제·DB 공통 모듈화를 진행했습니다. 원고를 오디오북으로 옮기기 위해 ePub/PDF 파서, OCR(PP-Structure), DAW 편집 기능을 구현했습니다.
변화
성우가 일일이 녹음→성우 없이 대용량 텍스트를 오디오북으로 생산

일하는 방식

누구나 쓰는 팀 개발 플랫폼 · AI Agent 하네스

현장
개발·배포 과정이 특정 지식을 가진 사람에게 의존하고, 팀원마다 AI 산출물의 품질이 달라집니다.
해결
지식이 없어도 개발 요소와 배포를 자동으로 진행할 수 있는 팀 내 플랫폼을 만들어 배포·운영합니다. AI Agent 하네스를 유지관리하며 모든 팀원의 AI 산출물이 일정한 품질을 유지하도록 꾸준히 개선합니다. 데이터 검증·마이그레이션 툴 개발, 코드 컨벤션 문서화, 사내 기술 세미나도 같은 맥락에서 진행했습니다.
